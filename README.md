## Learning Objectives

The practical work is intended to build understanding of:
- Password auditing and the purpose of password-cracking tools.
- The importance of password strength and resistance to guessing.
- How lab evidence and tool output should be interpreted.
- Defensive practices such as unique passwords and multi-factor authentication.
- Secure handling of password hashes and recovered credentials.
